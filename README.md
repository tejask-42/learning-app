# Learning App

An interactive learning application: learners log in, work through courses made of text, video, and quiz content, and every interaction (page views, clicks, video playback, quiz attempts) is captured as clickstream data.

**Status:** scaffolding in progress.

## Stack

- **Frontend:** React (Vite)
- **Backend:** Flask (Python)
- **Database:** PostgreSQL (hosted on [Neon](https://neon.tech))
